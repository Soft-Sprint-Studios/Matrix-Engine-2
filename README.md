# Matrix Engine 2

Matrix Engine 2 is a custom game engine, based on Pathos Engine
Originally we were working on our custom from scratch Tectonic Engine 2, however we found out that using valve hammer editor and compile tools for maps is a legally gray area which is why we decided to start work on Matrix Engine 2
for original Pathos and its credits view https://github.com/TheOverfloater/pathos-public

# Features
Physically Based Rendering (PBR)

Displacements

Physics (Bullet)

High Dynamic Range

Discord RPC and Sentry crash report integration

Custom PBSPV3 updated to have checksum and displacements + map sizes bigger then 32k

Blended textures

Deleted multipass

Parallax Occlusion Mapping

Replace SDL2 with SDL3

SSAO
